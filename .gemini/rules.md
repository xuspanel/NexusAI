# 🔒 NexusAI Project Directives & Git Rules

## Git & GitHub Operations Rule
- **ALWAYS ASK FOR EXPLICIT USER CONFIRMATION** before performing any `git commit` or `git push` operations to the GitHub Repository (`https://github.com/xuspanel/NexusAI.git`).
- **NEVER** automatically commit or push code changes without prior explicit approval or request from the user.
- Local code modifications, file writes, tests, and builds may proceed as requested, but staging, committing, and pushing to remote git branches MUST require explicit user instruction or confirmation.
